GAME GRAVE - GAMES MULTI-LAUNCHER WINDOWS PREVIEW 0.2.13

Only Games is reopened for changes. Overview remains at preview 0.2.12;
Ready Room and every other tab retain their existing source and rendering.
The owner's locked photos remain the visual foundation.

Games has live, clickable launcher cards for Steam, Epic, EA, Rockstar,
Battle.net, Ubisoft, Xbox PC, GOG and Other. Other includes Riot and custom
folders; the launcher filter can select each detected launcher separately.
Counts represent local installation records, not online account ownership.
Games additionally reads game-specific Rockstar / legacy EA registry records
in both Windows registry views. These extra records remain local to Games.

Each game has a cover card with its launcher badge. Local covers, chosen
artwork and cached official art work offline across launchers. Game options
can choose artwork, reset it, download an exact public-title match from Steam,
or choose a Steam artwork ID without changing the game's actual launcher.
Games without an exact cover retain a labeled local fallback; this preview
does not claim a verified official poster exists for every possible title.
Downloads send public titles/app IDs only and can be canceled.

Steam/Epic Play uses verified installation identities. For other launchers,
Play offers a game EXE chooser, saves that choice and revalidates it before
launching. Steam verify/DLC/uninstall open Steam's native controls; uninstall
requires confirmation and does not directly delete game files. Other
launchers' management buttons explain their native repair/DLC/uninstall
workflow when no verified direct shortcut is exposed. Online ownership,
update availability and unsupported playtime remain explicitly unknown.

Right-click operates on the clicked game. Favorites persist across app
restarts. Search, filters, sort, grid/list, keyboard launch, artwork menu,
installation folders, Save Vault entry and narrow Details drawer are checked
with actual Qt input. The full Games journey runs in three fresh processes.
The other twelve tabs undergo 72 exact pixel comparisons.

Included images use explicitly disposable QA installations, not the owner's
PC or library. Test covers include local reference crops and clearly
synthetic pictures. Build-Info.txt identifies the source commit and Windows
build; SHA256SUMS.txt identifies both EXEs. This is an unsigned preview.
The owner decides when Games is complete; passing checks is not signoff.
