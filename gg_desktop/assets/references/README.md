# Owner-supplied visual references

These are the eight unmodified reference images attached to the November 5, 2026
requests to reproduce Games, Mods, Old Files, Other Storage, Captures, Graveyard,
Game DNA and Undo Center. The repeated Undo attachment is stored once.
The desktop renders small artwork regions
from them: the GG wordmark, forest, header scenes and matching game covers.
Navigation, text, statistics, tables, selection and actions are native Qt widgets.
No screenshot is used as a substitute for an interactive page.

Game art is only selected when a detected game's title matches that cover.
Other games get a local title treatment. No remote artwork requests are made.
Normal capture galleries never use these images as the user's screenshots.
The isolated preview renderer creates explicitly labeled disposable fixtures
from the capture reference; real screenshots are decoded only on Preview.
These references do not establish redistribution rights for third-party game art;
the existing production asset review remains applicable before distribution.
