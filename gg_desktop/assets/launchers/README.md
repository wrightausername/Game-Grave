# Launcher marks

Game Grave draws a clean vector monogram badge for each launcher (Epic, EA, Battle.net, Ubisoft, Xbox, GOG, Rockstar).

To show a launcher's official mark instead, drop its artwork here, named after the launcher key, as an SVG (best)
or a large PNG with a transparent background:

    epic.svg   ea.svg   battlenet.svg   ubisoft.svg   xbox.svg   gog.svg   rockstar.svg

The file is picked up automatically and rendered at the real screen resolution. Use the artwork each company
publishes in its own brand or press kit.
